# AI Maintenance Predictor

## Overview

Hotel-এর equipment এবং room maintenance issues predictively detect করা — reactive maintenance (ভাঙলে ঠিক করো) থেকে proactive maintenance (ভাঙার আগেই ঠিক করো) তে shift করা।

---

## Goals

- Recurring maintenance patterns identify করা ("AC in rooms 201–210 breaks every July")
- Maintenance backlog intelligent prioritization
- Vendor/contractor performance tracking
- Preventive maintenance schedule auto-generation
- Cost tracking and budget forecasting

---

## How It Works

```
Maintenance Requests (ongoing data)
├── Issue type, room, description
├── Resolution time, cost
├── Frequency per room/equipment
└── Seasonal patterns
         ↓
AI Pattern Analysis (weekly)
├── "Room 305 AC has failed 3x in 6 months → schedule inspection"
├── "Plumbing issues spike in July → proactive check needed"
├── "Vendor X avg resolution time: 4 days (poor)"
└── Equipment age + failure rate → replacement recommendation
         ↓
Predictive Alerts + Preventive Schedule
         ↓
Manager Dashboard + Work Orders
```

## Database Schema

```prisma
model MaintenanceRequest {
  id           String   @id @default(cuid())
  hotelId      String
  roomId       String?
  area         String?  // "lobby" | "pool" | "restaurant" | "gym"
  reportedById String
  assignedToId String?
  vendorId     String?

  category     String   // "plumbing" | "electrical" | "hvac" | "furniture" | "it" | "structural"
  priority     String   @default("medium") // "low" | "medium" | "high" | "emergency"
  title        String
  description  String
  photos       Json?

  status          String   @default("open") // "open" | "in_progress" | "resolved" | "deferred"
  estimatedCost   Float?
  actualCost      Float?
  resolvedAt      DateTime?
  resolutionNotes String?

  isPreventive    Boolean  @default(false)
  aiGenerated     Boolean  @default(false)  // generated by AI predictor

  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt

  hotel      Hotel @relation(fields: [hotelId], references: [id])
  room       Room? @relation(fields: [roomId], references: [id])
  reportedBy User  @relation("ReportedBy", fields: [reportedById], references: [id])
  assignedTo User? @relation("AssignedTo", fields: [assignedToId], references: [id])
}

model PreventiveSchedule {
  id          String   @id @default(cuid())
  hotelId     String
  roomId      String?
  area        String?
  taskName    String
  category    String
  frequency   String   // "weekly" | "monthly" | "quarterly" | "annually"
  nextDueDate DateTime
  lastDoneAt  DateTime?
  aiSuggested Boolean  @default(false)
  notes       String?

  hotel Hotel @relation(fields: [hotelId], references: [id])
}

model MaintenanceVendor {
  id           String   @id @default(cuid())
  hotelId      String
  name         String
  category     String   // what type of work they do
  contactPhone String?
  contactEmail String?
  avgResponseTime Float? // hours
  avgRating    Float?
  isPreferred  Boolean  @default(false)
  notes        String?

  hotel Hotel @relation(fields: [hotelId], references: [id])
}
```

## AI Prediction Prompt

```
Analyze maintenance history for {hotelName} and identify patterns.

Maintenance data (last 12 months):
{list of requests with: room, category, date, resolution_days, cost, recurrence_count}

Identify:
1. Rooms or equipment with high failure frequency
2. Seasonal patterns
3. Vendor performance issues
4. Recommended preventive maintenance actions

Return JSON:
{
  "alerts": [
    {
      "type": "recurring_issue|seasonal_risk|vendor_concern",
      "severity": "low|medium|high",
      "description": "...",
      "affectedRooms": [...],
      "recommendedAction": "...",
      "estimatedCostSaving": number
    }
  ],
  "preventiveSchedule": [
    {
      "taskName": "...",
      "roomId/area": "...",
      "suggestedFrequency": "monthly",
      "reason": "..."
    }
  ],
  "summary": "Brief overview for manager"
}
```

## API Endpoints

```
GET  /api/maintenance                         — list requests (filtered)
POST /api/maintenance                         — create request
PUT  /api/maintenance/:id                     — update status/assign
PUT  /api/maintenance/:id/resolve             — mark resolved with cost
GET  /api/maintenance/analytics               — cost, resolution time stats
GET  /api/ai/maintenance/predictions          — AI alerts + predictions
POST /api/ai/maintenance/analyze              — trigger AI analysis
GET  /api/maintenance/preventive              — preventive schedule
POST /api/maintenance/preventive              — add preventive task
GET  /api/maintenance/vendors                 — vendor list + performance
```
