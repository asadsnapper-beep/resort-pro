# ResortPro Tutorial Video Plan

এই folder-এ ResortPro-এর customer tutorial video বানানোর পুরো plan রাখা হবে।
লক্ষ্য হলো: non-technical resort owner যেন video দেখে নিজে নিজে কাজ শুরু করতে পারে।

## মূল নীতি

- এক ভিডিওতে **একটি কাজ** শেখাবেন।
- সহজ বাংলা বলবেন; technical শব্দ এড়িয়ে চলবেন।
- প্রথম 10 সেকেন্ডে বলবেন, “এই video দেখে আপনার কী লাভ হবে।”
- বাস্তব resort-এর মতো sample data ব্যবহার করবেন, যেমন **Sea Breeze Resort**।
- demo account-এ আসল guest, phone number, NID, card বা payment data ব্যবহার করবেন না।
- কোনো feature পুরোপুরি ঠিক না থাকলে সেটি tutorial-এ দেখাবেন না; আগে fix ও retest করবেন।

## Video format

প্রতিটি normal tutorial এই 5-part structure follow করবে:

1. **Problem (0–10 sec):** “খাতায় booking রাখলে কোন room ফাঁকা আছে খুঁজতে সময় লাগে।”
2. **Promise (10–20 sec):** “এই video-তে 3 মিনিটে room add করে booking নেওয়া দেখাব।”
3. **Live steps:** একবারে একটি click; cursor বড় ও ধীর রাখবেন।
4. **Result:** “এখন এই room booking নেওয়ার জন্য ready।”
5. **Next step:** পরের video-এর clear link দিন।

## Language and tone

- Main version: সহজ Bangla, প্রয়োজন হলে পরিচিত English word: “booking”, “room”, “check-in”।
- Voice: শান্ত, সহায়ক, কোনো judgement নয়।
- বলবেন না: SaaS, CRM, workflow, automation, database, integration।
- বলবেন: “সব তথ্য এক জায়গায় থাকবে”, “ভুল কম হবে”, “আজ কী কাজ আছে দেখা যাবে।”

## Recording setup

### Software

- Screen recording: **Screen Studio** (Mac) অথবা **OBS Studio**।
- Simple fast recording: **Loom**।
- Editing: **CapCut Desktop** বা **Screen Studio**।
- Microphone: quiet room + wired earphone mic দিয়ে শুরু করা যায়; পরে USB microphone নিলে quality ভালো হবে।

### Screen preparation

1. Browser zoom 110–125% রাখুন, যাতে text সহজে পড়া যায়।
2. Desktop notifications, WhatsApp, email এবং personal tabs বন্ধ করুন।
3. Training-only resort ব্যবহার করুন: `Sea Breeze Resort`।
4. আগে থেকে sample rooms, sample guest এবং safe sample booking রাখুন।
5. Browser-এ শুধু প্রয়োজনীয় tab খুলুন।
6. Demo data reset করার checklist রাখুন, যাতে পরের video clean অবস্থায় শুরু হয়।

### Visual style

- 16:9 landscape: YouTube/Facebook full tutorial।
- 9:16 vertical: Facebook Reel/Instagram short tip।
- Recording 1440p হলে ভালো; export 1080p।
- Cursor highlight ব্যবহার করুন, কিন্তু অতিরিক্ত zoom/animation নয়।
- Important click-এর আগে 1 second pause দিন।
- Long loading, typing mistake ও unnecessary scrolling edit করে বাদ দিন।

## Video-by-video outline

### 1. ResortPro in 90 seconds

**Opening:** “আপনার booking, room আর guest-এর তথ্য কি অনেক জায়গায় ছড়িয়ে থাকে? ResortPro সব এক জায়গায় আনে।”

Show only:

- Dashboard-এর আজকের booking
- Available/occupied room
- New Booking button
- Front Desk
- Revenue/report preview

**Ending:** “এখন চলুন, প্রথমে আপনার resort setup করি।”

### 2. First-time setup

Show:

1. Login
2. Resort profile/settings
3. Currency, check-in/check-out time
4. First room add
5. Confirm the dashboard is ready

**Do not show:** advanced settings, API, custom CSS, payment gateway.

### 3. Add a room

Show:

1. Go to **Rooms**
2. Click **Add Room**
3. Give a room name and number
4. Add nightly price, guest capacity and amenities
5. Save
6. Show the new room in the room list

**Key message:** “Room আগে add করলে booking-এর সময় ভুল room দেওয়ার chance কমে।”

### 4. Take a new booking

Show:

1. Go to **Bookings**
2. Click **New Booking**
3. Select check-in and check-out date
4. Select available room
5. Add guest name and phone
6. Review and create the booking
7. Show it on the booking list/calendar

**Key message:** “Booking save হওয়ার পর room availability automatically update হয়েছে কি না দেখান।”

### 5. Walk-in guest check-in

Show:

1. Go to **Front Desk**
2. Click **Walk-in**
3. Select guest, room and dates
4. Add document if this flow supports it
5. Confirm check-in
6. Show today’s arrival/check-in list

**Important:** Bookings page এবং Front Desk page-এর Walk-in flow একই না হলে, owner-কে বিভ্রান্ত না করে শুধু verified Front Desk flow দেখাবেন।

### 6. Guest information and documents

Show:

1. Open **Guests**
2. Find a guest
3. Open profile
4. Add or view document
5. Explain where the document is visible later

**Before recording:** Booking Detail page-এ document visibility fix এবং retest করতে হবে।

### 7. Check-out, payment and invoice

Show:

1. Open today’s departure
2. Review room charge/extras
3. Record payment method
4. Complete check-out
5. Open/download invoice

**Before recording:** Invoice number concurrency fix must be deployed and tested.

### 8. Housekeeping and maintenance

Show:

1. Mark room as needs cleaning
2. Assign or view housekeeping task
3. Mark it clean
4. Create a maintenance issue for a broken item
5. Show room status update

### 9. Your booking website

Show:

1. Go to **Website**
2. Pick/preview a theme
3. Show public booking site
4. Select dates in availability calendar
5. Show available rooms
6. Explain how a guest starts booking

**Never use real payment details in recording.**

### 10. Daily report

Show:

1. Dashboard’s today cards
2. Occupancy
3. Today’s arrivals/departures
4. Revenue/report page

**Key message:** “সকালে 2 মিনিট দেখে বুঝবেন আজ কোন room, booking আর guest-এর কাজ আছে।”

## Editing checklist

- [ ] Title says the exact outcome, for example: “ResortPro-তে নতুন booking কীভাবে নিবেন”
- [ ] First 10 seconds clearly state the benefit
- [ ] No private data, passwords, email inbox, API key, payment key or real NID visible
- [ ] Cursor and text are readable on a phone screen
- [ ] Captions added in Bangla
- [ ] One clear next step at the end
- [ ] Thumbnail uses 3–5 words only
- [ ] Video checked from start to finish after export

## Publishing plan

### YouTube

- Publish the full tutorial series in a playlist: **ResortPro সহজে ব্যবহার করুন**.
- Use chapter timestamps for videos over 4 minutes.
- Put the next tutorial and sign-up link in the description and pinned comment.

### Facebook / Instagram

- Turn every full tutorial into 2–3 short tips (30–60 seconds).
- Example Reel title: “২ মিনিটে ResortPro-তে নতুন booking নিন”
- One reel = one action only.

1. **ResortPro কী?** — 90 seconds, product overview.
2. **প্রথম room add করুন** — the easiest practical win.
3. **নতুন booking নিন** — the most valuable daily workflow.
