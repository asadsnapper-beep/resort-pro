# ResortPro marketing workspace

This directory documents the working rules for ResortPro content and marketing.

## Context files

- `../../FOUNDER_CONTEXT.md` is the canonical positioning, audience, messaging,
  voice, pricing, terminology, and claim-safety reference.
- `../../.agents/social-media-context-sms.md` adapts that context for social
  platforms.
- `../../packages/types/src/plans.ts` is the canonical source for public plan
  names, prices, limits, and feature flags.

## Before publishing any asset

1. Confirm the audience, channel, objective, and single CTA.
2. Re-check any time-sensitive price, limit, feature, or integration claim.
3. Require evidence and permission for testimonials, logos, performance
   outcomes, customer counts, security claims, or comparative claims.
4. Review the draft against `FOUNDER_CONTEXT.md`.
5. Keep a final copy of the published asset and its source evidence in this
   directory or the campaign's designated system of record.

## Recommended next foundation work

- Founder answers the open decisions in `FOUNDER_CONTEXT.md`.
- Collect 5-10 founder-authored posts to establish a personal social voice.
- Build a verified proof library with customer consent, quotes, metrics, and
  source links.
- Choose the next 90-day acquisition objective before creating a full campaign
  calendar.
