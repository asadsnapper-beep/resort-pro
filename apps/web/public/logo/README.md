# ResortPro logo assets

This is the canonical export folder for the approved ResortPro identity. All
files are derived from the same approved master; do not re-typeset the custom
`resortpro` wordmark with a substitute font.

## Web logos

- `resortpro-logo-web.png` — primary transparent horizontal logo, 1280×360.
- `resortpro-logo-web-640.png` — smaller transparent web export.
- `resortpro-logo-reversed.png` — white transparent logo for dark surfaces.
- `resortpro-symbol-master-1024.png` — transparent standalone R/Pro symbol.
- `resortpro-symbol-{16,32,48,64,128,256,512}.png` — transparent symbol sizes.

## Browser and PWA icons

- `favicon.ico` — multi-size 16/32/48 Windows/browser favicon.
- `favicon-{16,32,48}.png` — explicit browser favicon sizes.
- `apple-touch-icon.png` — 180×180 Apple touch icon.
- `android-chrome-{192,512}.png` — PWA icons.
- `maskable-icon-512.png` — safe-area PWA maskable icon.
- `resortpro-app-icon-master-1024.png` — square app-icon master.

## Social and presentation exports

- `resortpro-logo-banner-1200x630.png` — Open Graph and social sharing card.
- `resortpro-logo-landscape-1600x900.png` — landscape presentation asset.
- `resortpro-logo-portrait-1080x1350.png` — portrait social asset.
- `resortpro-logo-square-{512,1024}.png` — square profile assets.
- `resortpro-logo-thumbnail-256.png` — compact preview/profile asset.

## Brand colours

- Deep navy: `#0E223C`
- Signal lime: `#BEF264`
- Warm canvas: `#F8F6F1`

Keep clear space around the logo equal to at least half the symbol height. Do
not stretch, rotate, recolour, add shadows, or separate the custom wordmark
letters.
