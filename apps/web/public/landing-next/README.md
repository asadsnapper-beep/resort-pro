# Landing Page Visual Assets

This folder contains the approved visual assets for the next ResortPro landing-page design.

| File | Use | Guidance |
|---|---|---|
| `hero-dashboard-resortpro.png` | Hero product proof | Show it large, inside a soft browser/window frame. Crop only if the key cards remain readable: rooms, bookings, check-ins and revenue. |
| `resort-owner-at-desk.png` | Optional trust or lifestyle section | Wide supporting visual. Place copy in the intentionally clear space on the left; do not overlay dense text over the owner. |
| `testimonial-owner-avatar.png` | Testimonial card | Crop as a circular 56–72px avatar. Use it only with a clearly labelled illustrative/example testimonial until a verified customer quote and permission are available. |

## Usage rules

- Prefer `next/image` with meaningful alt text.
- Do not use generated owner images to imply a real named customer endorsement.
- Keep the hero dashboard as the primary image; it proves what the product does.
- Use the lifestyle image once at most. The page should remain simple and not become image-heavy.
