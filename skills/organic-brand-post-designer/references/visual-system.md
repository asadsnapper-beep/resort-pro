# Distinctive visual-system method

Use this when the task covers a campaign, recurring series, or a brand without a usable visual system.

## 1. Extract the brand DNA

Create a compact decision map:

| Layer | Decide | Examples of evidence |
|---|---|---|
| Truth | What the brand knows or sees that others miss | operator insight, founder belief, customer behavior |
| Emotional temperature | How the work should feel | calm, candid, warm, urgent, playful, exact |
| Visual world | What environments and materials belong | real locations, tools, documents, textiles, screens |
| Type behavior | How the brand speaks visually | editorial serif, compact grotesk, generous sentence case |
| Color behavior | How color is used, not only which colors | quiet field plus one signal color, warm neutrals, duotone |
| Composition | Recurring spatial logic | left rail, oversized crop, modular field, asymmetrical frame |
| Signature | A repeatable but flexible cue | date stamp, route line, annotated margin, shaped crop |
| Prohibitions | What would misrepresent the brand | luxury clichés, fake people, tech neon, loud gradients |

Choose a small set of anchors strong enough to make unrelated posts feel related. A signature cue should survive different subjects and formats without becoming a watermark or rigid template.

## 2. Create contrast with the category

Map the category defaults before choosing a direction. Note common palettes, imagery, layout conventions, metaphors, and claims. Select one or two defaults to keep for comprehension and one meaningful convention to challenge.

Distinctiveness is not novelty for its own sake. Preserve enough category recognition for the audience to understand the post quickly.

## 3. Define variation rules

Separate constants from variables.

**Constants** may include logo handling, core palette, typographic roles, spacing rhythm, photo treatment, and one signature device.

**Variables** may include crop, background field, accent color, illustration method, headline scale, texture, or layout tension.

Change only the variables needed to express the current idea. This keeps the system alive without losing recognition.

## 4. Build three benchmark posts

Test the system on meaningfully different content:

1. an educational or insight-led post;
2. a product/proof post;
3. a human, founder, or behind-the-scenes post.

If the three posts look identical, the system is a template. If they look unrelated, the anchors are too weak. Refine until they feel like members of one family with different personalities.

## 5. Document operational rules

Record only reusable decisions: type roles, color behavior, layout anchors, photo direction, motif rules, logo placement range, content density, accessibility minimums, and examples of “on brand” versus “too generic.” Avoid documenting every pixel of one composition as a universal rule.
